## المصطلحات

- صعود الماي = **سجي**، نزول الماي = **ثبر**، وقت الثبات = **وقفة** (بدون أقواس أو شرح).
- كل يوم عليه **حمل** أو **فساد**.

## الشاشات

1. **البحر**: شعار + «سجي» + المكان → بطاقة الحالة (سجي/ثبر + حمل/فساد | الوقفة الجاية + كم باقي) مع موجتين متحركتين وقارب يتمايل → شريط الأيام (اسم اليوم، التاريخ، شكل القمر، حمل/فساد) → منحنى المد والجزر مع نقطة «الحين» وأوقات المد والجزر → الرياح (سهم الاتجاه) · الضغط (عداد) · حمل/فساد (تيار قوي/خفيف) → زر «سجّل صيدة · AI».
2. **الكاميرا**: إطار بزوايا، شارة «AI · يتعرف على السمكة»، زر تصوير، ألبوم.
3. **التعرف**: خط مسح متحرك + «قاعد أتعرف على السمكة…».
4. **النتيجة**: اسم السمكة + نسبة التأكد → الأسماك الشائعة (هامور، شعم، مزيزي، سبيطي، ينم) + «نوع ثاني» (بحث/كتابة/اختيار) → التاريخ والساعة وحمل/فساد ووقت الماي والضغط تلقائي → طريقة الصيد → المكان → «حفظ في صيدي».
5. **صيدي**: إحصائيات (صيدات، أنواع، أكثر طريقة) → أزرار الأسماك (الكل + الشائعة + أي سمكة سجّلها المستخدم) + «نوع ثاني» اختياري → بطاقات الصيد (صورة، النوع، التاريخ والساعة، حمل/فساد، وقت الماي، الطريقة، المكان).
6. **أفضل وقت لسمكة**: نسب حمل/فساد بأعمدة + أغلب وقت ماي + أغلب وقت باليوم، محسوبة من صيدات المستخدم فقط.
7. **حسابي**: اسم مستخدم، صورة بحلقة ملونة، عدد الصور/الصيدات/الأنواع، نبذة ومعلومات (المنطقة، الخبرة، الطراد، أكثر سمكة)، صور مميزة، شبكة صور 3 أعمدة.
8. **صورة منشورة**: صورة مربعة، إعجاب، تعليق، مشاركة، الوصف، معلومات الصيدة.
9–10. **إضافة صورة**: سلفي أو ألبوم → ربط بصيدة → وصف → مين يشوفها (الكل/أصحابي/أنا بس) → انشر.
